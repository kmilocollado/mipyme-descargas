# mipyme · descargas

Instalador de **mipyme**, el programa de ventas, inventario y caja que funciona sin internet.

**Descargar la última versión:** [mipyme-Setup.exe](https://github.com/kmilocollado/mipyme-descargas/releases/latest/download/mipyme-Setup.exe)

Requisitos: Windows 10 u 11 (64 bits). Incluye una prueba gratuita de 7 días.

Más información en <https://mipyme.space>.

> Si Windows muestra "Windows protegió su PC", pulsa **Más información → Ejecutar de todas formas**.
